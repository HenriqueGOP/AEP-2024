# AEP-2024 — exercício em C

Projeto acadêmico desenvolvido em **linguagem C**, com interface de terminal e lógica de simulação de triagem e orientações gerais.

## O que o código demonstra

- Organização de funções e menus.
- Entrada e validação básica de dados.
- Uso de arrays e strings.
- Controle de fluxo e histórico limitado de operações.

## Arquivo principal

[AEP.c](AEP.c)

## Como compilar

Com um compilador C, por exemplo GCC:

```bash
gcc AEP.c -o aep
```

No Windows, execute `aep.exe`. No Linux/macOS, execute `./aep`.

> **Aviso:** projeto educacional, sem finalidade de diagnóstico ou aconselhamento médico. Os códigos originais foram preservados.
